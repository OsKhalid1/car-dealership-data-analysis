# 🚗 Car Dealership Data Analysis

## 📌 Project Overview
This project analyzes dealership data including used and new cars.

## 🔍 Key Insights
- Newer cars tend to have higher prices.
- Higher mileage decreases car value.
- Petrol is the most common fuel type.
